## Canonical command

Per `CLAUDE.md` §9 and `apps/backend/pytest.ini`:

```
python -m pytest              # from apps/backend/
```

`pytest.ini` sets `pythonpath = .`, `testpaths = tests`,
`python_files = test_*.py`. There is no separate runner script, no tox, no make
target. Selection is by path or `-k`.

The full suite must be green before every commit (`CLAUDE.md` §13).

## Migration verification

There is no dedicated migration test suite. Migrations are verified by running
them against a **scratch database**:

```
export SUBSTATIONOS_DATABASE_URL="sqlite:///<a temp file>"
python -m alembic upgrade head
python -m alembic downgrade -1
python -m alembic upgrade head
python -m alembic heads          # must show exactly one head
```

Then check: no `_alembic_tmp_*` tables survive, the recorded version is correct
after any refusal, and ORM/migration schemas agree (compare
`inspect(engine).get_unique_constraints(...)` against
`Base.metadata.tables[...]`).

**Never test destructively against `apps/backend/substationos.db`.** Single head
at this baseline: `e5a2f7b91c60`.

## Test-quality signals worth knowing

The repository has been bitten by tests that pass for the wrong reason. Three
patterns are now guarded, and you should preserve them:

**1. `reused=False` does not prove recomputation.** A *failed* result also
carries `reused=False`. Tests asserting that a stage recomputed must also assert
`succeeded is True` — otherwise a regression turning recomputation into a
refusal stays green. See `tests/services/test_artifact_identity_reuse.py`, where
every recomputation assertion is paired with a success assertion and, where it
matters, with the persisted lineage
(`downstream.upstream_identity == upstream.artifact_identity`).

**2. An ad-hoc version argument is not a policy bump.** Every
`SUPPORTED_*_VERSIONS` set is a singleton derived from its policy constant, so
passing an invented version produces an `UNSUPPORTED` refusal rather than the
recomputation a genuine bump produces. Tests simulating a bump patch the derived
supported set too.

**3. Mutation testing.** Several invariants were verified by temporarily
removing the guard and confirming the test fails. A fitness test that passes
against broken code protects nothing.

## Minimum regression selection

Derived from the dependency direction: **a change invalidates its own stage and
everything downstream.** These are starting sets, not proof of completeness —
trace actual importers before trusting them.

| Changing | Run at minimum |
|---|---|
| Canonical PDF / parser | Canonical PDF+Text, Evidence, Entities, Facts, Semantics, Artifact identity, Architecture, AF-01, integration |
| Canonical Text / segmentation | Canonical Text, Evidence and everything downstream, Artifact identity, Architecture, AF-01, integration |
| Evidence grammar or extraction policy | Evidence (incl. corpus), Entities, Facts, Semantics, Artifact identity, Architecture, AF-01, integration |
| Entity resolution or entity contract | Entities, Facts, Semantics, Artifact identity, Architecture, AF-01, integration |
| Fact policy/contract or predicates | Facts, Semantics, Graph+Promotion, Artifact identity, Architecture, AF-01 |
| Semantic policy/contract or statement types | Semantics, Human Review, Graph+Promotion, Retrieval+Context, Artifact identity, Architecture, AF-01 |
| Human Review | Human Review, Graph+Promotion, Architecture, AF-01 |
| Promotion or graph | Graph+Promotion, Retrieval+Context, Architecture, AF-01 |
| Retrieval or context assembly | Retrieval+Context, Architecture, AF-01 |
| Reasoning | Structural, Retrieval+Context, Architecture, AF-01 |
| A port, model or migration | The owning context, Artifact identity, Architecture, migration verification |
| A router or schema | API (incl. OpenAPI), the owning context, Architecture |

**A reduced selection never replaces the full suite where a milestone requires
it.** `CLAUDE.md` §13 requires `python -m pytest` fully green before every
commit.
